HTML Table — कदम दर कदम (Hindi)

नमस्ते! यह फ़ाइल HTML में table (तालिका) बनाने का आसान और क्रमिक तरीका बताती है। हर चरण में आप एक छोटा उदाहरण और उसके कोड को देखेंगे। ब्राउज़र में खुलते ही तालिकाएँ दिखेंगी और नीचे कोड भी दिया है — आप फ़ाइल को एडिट करके अभ्यास कर सकते हैं।

Step 1: साधारण तालिका (Basic table)

यह सबसे सरल तालिका है: rows (पंक्तियाँ) और columns (स्तंभ) <tr> और <td> से बनते हैं।

रोज़ाना नमूना 1 नमूना 2
सोमवार अ ब
मंगलवार स द
n

Code

<table>
  <tr>
    <td>रोज़ाना</td>
    <td>नमूना 1</td>
    <td>नमूना 2</td>
  </tr>
  <tr>...</tr>
</table>

Step 2: हेडर (Headers) — <th> और <thead>

तालिका के शीर्ष (header) में सामान्यतः <th> टैग का उपयोग किया जाता है — यह ब्राउज़र में बोल्ड और केंद्रित दिखता है। बड़े तालिकाओं में <thead> और <tbody> इस्तेमाल करें।

किताबों का सारांश
शीर्षक लेखक वर्ष
अलिफ लैला रचना 2020
सीखना उदाहरण 2018

Code

<table>
  <caption>किताबों का सारांश</caption>
  <thead>
    <tr>
      <th>शीर्षक</th>
      <th>लेखक</th>
      <th>वर्ष</th>
    </tr>
  </thead>
  <tbody>...</tbody>
</table>

Step 3: फुटर (Footer) — <tfoot>

आप चाहें तो तालिका का सार (या कुल) नीचे दिखाने के लिए <tfoot> भी जोड़ सकते हैं।

प्रोडक्टमूल्य
आ100
इ200
कुल300

Code

<table>
  <thead><tr>...</tr></thead>
  <tbody>...</tbody>
  <tfoot><tr>...</tr></tfoot>
</table>

Step 4: colspan और rowspan (Columns/Rows Merge)

कभी-कभी किसी सेल को कई कॉलम या कई पंक्तियों में फैला (merge) करना होता है — इसके लिए colspan और rowspan का उपयोग करें। नीचे उदाहरण देखें।

नाम विवरण नोट्स
अमित डिज़ाइनर पार्ट-टाइम
अनुभव: 3 साल

Code

<tr>
  <td rowspan="2">अमित</td>
  <td>डिज़ाइनर</td>
  <td>पार्ट-टाइम</td>
</tr>
<tr>
  <td colspan="2">अनुभव: 3 साल</td>
</tr>

Step 5: CSS से स्टाइल (Styling)

तालिका को बेहतर दिखाने के लिए CSS का उपयोग करें — border-collapse, padding, hover effects आदि बहुत उपयोगी हैं। ऊपर की स्टाइल फ़ाइल में कुछ बुनियादी CSS पहले से है।

अगर चाहें, नीचे की तरह hover effect जोड़ सकते हैं (यह पहले से नहीं जोड़ा गया है, आप जोड़ कर देखें):

table tr:hover { background:#f9f9ef; }
