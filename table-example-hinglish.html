HTML Table — Hinglish Step-by-Step

Namaste! Yeh file simple Hinglish mein bata rahi hai kaise HTML mein table banate hain. Har step mein ek chhota example aur uska code diya hai — browser mein file open karke turant dekho aur edit karke practice karo.

Step 1: Basic table

Simple table mein rows banate hain <tr> se aur cells <td> se.

Day Sample 1 Sample 2
Monday A B
Tuesday C D

Code

<table>
  <tr>
    <td>Day</td>
    <td>Sample 1</td>
    <td>Sample 2</td>
  </tr>
  <tr>...</tr>
</table>

Step 2: Header — <th> and <thead>

Table header ke liye <th> use karte hain. Badi tables mein <thead> aur <tbody> helpful hote hain.

Books Summary
Title Author Year
Alif Laila Rachna 2020
Sikhna Udaharan 2018

Code

<table>
  <caption>Books Summary</caption>
  <thead>
    <tr>
      <th>Title</th>
      <th>Author</th>
      <th>Year</th>
    </tr>
  </thead>
  <tbody>...</tbody>
</table>

Step 3: Footer — <tfoot>

Agar table ka total ya summary dikhana ho to <tfoot> use karo.

ProductPrice
A100
B200
Total300

Code

<table>
  <thead><tr>...</tr></thead>
  <tbody>...</tbody>
  <tfoot><tr>...</tr></tfoot>
</table>

Step 4: colspan and rowspan (merge cells)

Kisi cell ko multiple columns ya rows mein spread karna ho to colspan aur rowspan use karo.

Name Role Notes
Amit Designer Part-time
Experience: 3 years

Code

<tr>
  <td rowspan="2">Amit</td>
  <td>Designer</td>
  <td>Part-time</td>
</tr>
<tr>
  <td colspan="2">Experience: 3 years</td>
</tr>

Step 5: CSS styling

Table ko acha dikhane ke liye CSS use karo — border-collapse, padding, hover effects. Upar already kuch basic CSS add kiya hua hai.

Example hover add karne ke liye (aap isko file mein add karke dekho):

table tr:hover { background:#f9f9ef; }
